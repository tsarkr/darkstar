Everything an ontologist needs

No plugins required for the essentials. No Electron. No waiting.

🧠

Parallel Reasoning Engine

Full OWL 2 RL forward-chaining inference powered by Rayon. Watch thousands of triples materialize in real time.

🔎

Inference Explanations

Every inferred triple, proven. Trace exactly which rules and premises produced it in the dedicated justification view.

📝

SPARQL 1.1 + DL Query

Full SPARQL 1.1 (BGP, FILTER, OPTIONAL, aggregates) and Manchester Syntax class expressions like hasChild some Person.

🌌

Stunning Graph Visualization

Six layout algorithms, physics simulation with collision avoidance, curved bidirectional edges — at a smooth 60 FPS.

🧩

Dynamic Plugins

Load native plugins at runtime (.dylib / .so / .dll). Extend tabs, analysis, and transforms without recompiling.

📂

Multi-Format I/O

Turtle, RDF/XML, N-Triples. Recursive owl:imports resolution, full undo/redo history, consistency checking.
